## Files created

### CKAN-12
- `ckan-bridge/src/correction-propagator.ts` — `InMemoryCorrectionPropagator`:
  - Propagates Databox correction dispositions to CKAN (ADR-0023)
  - Handles all 6 dispositions: corrected, statement-associated, partially-corrected, no-change, more-information-required, redirected
  - Per-recipient notification duties with state tracking
  - Lawful exception support (`hasLawfulException`)
  - Idempotent: deduplicates by sha256(podRecordIri:disposition:dispositionAt)
  - Records every correction in the disclosure ledger
  - `CorrectionPropagationError` with error codes

### CKAN-13
- `ckan-bridge/src/reconciliation.ts` — `InMemoryReconciliationService`:
  - Periodic sweeps comparing Pod state with CKAN state
  - Detects: editor-originated drift, orphaned-ckan (CKAN dataset deleted)
  - Configurable interval (default 300s)
  - Start/stop for periodic execution
  - `ReconciliationError` with error codes
